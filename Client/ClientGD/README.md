# I4.0 Client API for Godot

This are the GDScript bindings for *I4.0 Client API*.

> [!IMPORTANT]
> Most of the bindings are coded in GDScript, but the encryption I4.0 uses couldn't be coded using GDScript, so C# is used for the encryption.
> Make sure you have *.NET >= 8.0* and *Godot Mono >= 4.2*.
